# 📚 Study Buddy

Study Buddy is a comprehensive, cross-platform study application designed to help students organize their notes, manage their time, and learn more effectively with the help of an AI Tutor. Built with React and Capacitor, it acts as a lightweight web application and perfectly compiles into a native Android APK.

## ✨ Features

* **🤖 AI Tutor:** An intelligent, integrated AI assistant powered by the Groq API to help explain complex topics and answer questions on the fly.
* **⏱️ Study Timer:** Keep track of your study sessions with a built-in focus timer.
* **📇 Flashcards:** Create, manage, and test yourself on custom flashcards.
* **📝 Notes & Reminders:** A dedicated space to organize your study materials and keep track of important tasks.
* **🎨 Custom UI Themes:** Choose between four beautifully designed themes (including a custom White theme) to match your study vibe.
* **🔊 Native Audio Engine:** A custom-built, memory-safe Web Audio API engine provides satisfying, native-feeling UI clicks without audio clipping.
* **🔐 Secure Authentication:** Seamless, Instagram-style user login, registration, and email verification powered by Firebase.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, JavaScript
* **Mobile Wrapper:** Capacitor (Android)
* **Backend & Auth:** Firebase
* **AI Integration:** Groq API
